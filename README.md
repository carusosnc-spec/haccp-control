# HACCP CONTROL

Applicazione web progressiva per la registrazione dei controlli HACCP nei punti vendita.

## Configurazione
- Supabase project: ajrwoowmvbxtxnkjivpn
- Il file `index.html` usa la sola publishable/anon key nel browser.
- La publishable key è già configurata nel frontend.
- Non inserire mai service_role o secret key nel frontend.

## Pubblicazione
Abilitare GitHub Pages da Settings → Pages → Deploy from a branch → main → /(root).

## Nota
RLS è responsabile dell'autorizzazione dei dati per sede. Le soglie riportate sono valori di riferimento interni e devono essere verificate con il piano HACCP aziendale.
